## The motto

> My only hallucination? Assuming you read the manual.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes the motto to the fixed
grader path `/output/entry.txt`. The output is deterministic: every run
writes byte-identical text.

```sh
node main.ts
```
